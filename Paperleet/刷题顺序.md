# PaperLeet 刷题顺序

建议先完成 LLM 基础，再学习 Transformer 和训练基础；之后可以按兴趣分别进入 AI Infra、强化学习和机器人方向。每个目录中，`problem.md` 是题干，`solution.py` 是待补全的初始代码。

## 环境

在 `Paperleet` 目录下执行：

```bash
uv sync --locked
uv run python -c 'import torch; print(torch.__version__)'
```

项目使用 Python 3.14 和 CPU 版 PyTorch。完成代码后，可以用 `uv run python 路径/solution.py` 检查文件能否运行；该命令不会自动验证答案。本仓库没有收录题目测试，完整验证请在 [PaperLeet](https://paperleet.com/) 对应题目页面运行测试。

`problems/` 是 [PaperLeet 上游题库](https://github.com/PaperLeet/paperleet.github.io/tree/main/problems)的本地副本，包含参考解答和测试。快照对应上游提交 `dfaa6df21f2036f7db9709e86a01b588d8fe19ad`。

`rl/5_dr_grpo/solution.py` 使用上游 GRPO 的辅助代码；从 `Paperleet` 目录以模块方式运行，即可找到本地 `problems/`：

```bash
uv run python -m rl.5_dr_grpo.solution
```
